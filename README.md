# Wortschatz

PWA для набора словарного запаса: **немецкий, итальянский, английский**,
по 10 000 самых частотных слов на язык, с переводом на русский и английский,
интервальными повторениями и работой офлайн.

Всё в контейнерах: на машине нужен только Docker.

## Запуск локально

```bash
docker compose up -d --build
open http://localhost:8080
```

Порт меняется переменной `PORT` (см. `.env.example`).

## Деплой на VPS

Нужен Docker и домен, A-запись которого смотрит на сервер.

```bash
git clone <репозиторий> wortschatz && cd wortschatz
cp .env.example .env && nano .env        # вписать свой DOMAIN
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

Caddy сам получит сертификат Let's Encrypt и будет его продлевать.
HTTPS здесь не украшение: без него браузер не зарегистрирует service worker,
а значит не будет ни офлайна, ни установки приложения на телефон.

Обновление — обычный `git pull` и пересборка. Собранные `app/db/*.db` лежат
в репозитории, поэтому на сервере ничего парсить и качать не нужно.

## Пересборка словарей

Нужна, только если меняются источники или логика отбора слов.
Python и зависимости ставить не надо:

```bash
docker compose run --rm builder                 # все три языка
docker compose run --rm -e LANGS=it builder     # только итальянский
```

Скачает дампы в `data/<язык>/` (суммарно ~5,3 ГБ, кэшируется)
и перезапишет `app/db/wortschatz-<язык>.db`. Дальше пересобрать образ `web`.

## Как собраны словари

На каждый язык три источника:

| файл | что даёт |
|---|---|
| `freq.txt` | частотность словоформ (OpenSubtitles) |
| `main.jsonl` | английские значения, род, мн. ч., IPA, примеры (English Wiktionary) |
| `ru.jsonl` | русские значения (русский Викисловарь) |

Ключевая деталь: ранжируются **леммы**, а не словоформы. Из Wiktionary берётся
таблица форм каждой леммы, и частоты всех форм суммируются
(`ist` + `war` + `bin` + `gewesen` → `sein`). Иначе топ-10000 забивается
спряжениями десятка глаголов вместо новых слов. Омографы делят частоту.

Три ловушки, которые пришлось обойти — каждая искажала рейтинг целиком:

* в таблицах сложных времён вспомогательный глагол стоит отдельной формой
  (`habe geäugt` → форма `haben`), из-за чего частота `haben` размазывалась
  по всем глаголам языка — отсекается по метке `auxiliary`;
* у служебных слов Wiktionary ставит первым грамматическое описание
  (`sein` → «forms the present perfect»), поэтому главное значение выбирается
  по оценке, а не по порядку;
* частотный список целиком в нижнем регистре, а в немецком регистр значим:
  существительное `Ich` делило частоту с местоимением `ich` поровну и всплывало
  в топ. Лемма с заглавной буквы, конкурирующая со строчной, получает 5% доли —
  после этого в топе существительных встали `Frau`, `Mann`, `Jahr`, `Kind`.

Артикль считается по языку: для немецкого из рода, для итальянского с учётом
первых букв слова (`lo` перед s+согласная, z, gn, ps; `l'` перед гласной),
для английского его нет.

У английского как изучаемого языка `translation_en` — это **определение**
из английского Wiktionary, а не перевод; настоящий перевод там в `translation_ru`.

## Как устроено приложение

Базы `app/db/wortschatz-<язык>.db` скачиваются браузером целиком и открываются
через **sql.js** — SQLite, скомпилированный в WebAssembly. Сервер для запросов
не нужен, всё работает на клиенте.

SQLite синхронен, а загрузка базы занимает сотни миллисекунд, поэтому он
вынесен в **Web Worker** (`app/js/db-worker.js`). При переключении языка
предыдущая база закрывается: держать три в памяти — лишние десятки мегабайт.

Словари доступны только на чтение и заменяются целиком при обновлении, поэтому
прогресс хранится отдельно в IndexedDB (`app/js/progress.js`) с ключом
(профиль, язык, слово). Алгоритм повторений — **SM-2**, как в Anki.

## Маскот

`app/mascot/` — пять состояний: `idle`, `think`, `correct`, `wrong`, `celebrate`.
Сейчас там заглушки. Чтобы поставить свой рисунок, перезапиши эти файлы,
сохранив имена; в коде менять ничего не нужно. Для растра поменяй `EXT`
в начале `app/js/mascot.js`. Если файла нет, слот схлопывается и приложение
работает без картинки.

## Структура

```
app/              то, что раздаётся nginx
  index.html
  css/ js/        интерфейс, воркер с SQLite, прогресс, маскот
  vendor/         sql.js (wasm), в репозитории ради офлайна
  db/             собранные словари по языкам
  mascot/         состояния маскота
  sw.js           офлайн-кэш
scripts/
  fetch_sources.sh  качает дампы в data/<язык>/
  build_db.py       собирает базы (только стандартная библиотека Python)
data/             сырые дампы, в git не хранятся
```

# Wortschatz

PWA для набора немецкого словарного запаса: 10 000 самых частотных лемм
(≈ уровень C1) с переводом на английский и русский, интервальные повторения,
полностью офлайн.

## Как собрана база

`scripts/fetch_sources.sh` качает два-три источника в `data/`:

| файл | размер | что даёт |
|---|---|---|
| `de_50k.txt` | 1 МБ | частотность словоформ (OpenSubtitles) |
| `kaikki-de.jsonl` | 1 ГБ | английские значения, род, мн. ч., IPA, примеры |
| `kaikki-ru.jsonl` | 113 МБ | русские значения |

`scripts/build_db.py` сводит их в `app/wortschatz.db`:
частоты словоформ суммируются на лемму (`ist`+`war`+`bin` → `sein`),
леммы ранжируются, берутся первые 10 000.

Сырые дампы в git не хранятся, готовая база — хранится.
